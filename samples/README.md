# Samples

Static, one-off sample pages. They are not served by the app and are not connected to Supabase.

- `margin-check.html`: margin before vs after the Shopee fee for 87 Shopee MY products (Avixo cost as of 1 Nov 2026,
  latest Shopee MY listing price). Open the file in a browser. Contains real cost data, so keep this repo private.
- `stock-take-test.html`: Bulk Stock Take test page, kept for reference.
