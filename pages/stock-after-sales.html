Stock after sales

How to use (read first)
  1. Put each file in its own box: Inventory (the Avixo report staff uploaded), Shopee MY, Shopee SG, Shopee PH, TikTok. Or pick them all at once and the boxes fill by file name (name them with MY, SG, PH, TT or TikTok). Leave a box empty if there is no file.
  2. Press Preview. The page takes the stock from the Avixo report and subtracts the units sold, product by product. It does not touch the inventory app.
  3. Copy the table (or download the CSV) and update Avixo. The Remark column is ready to paste, for example 17112026 MY x1 SG x1: the sales date, then each platform that sold.
  4. Press Save to history so you can check this calculation later in the History tab. Saving does not change any stock. The same sales file can be saved only once.

To match TikTok sales exactly, add the ID to the product Comments (remark) in Avixo, separated by ;: TT|product id|0. Shopee uses MY|item id|variation id, SG|…, PH|…. Use 0 when there are no variations. Without a remark in Avixo, a product is matched by name only when the match is clear (marked "check"); anything unclear is listed as not matched.

Every saved calculation is kept here, so you can check later which files were used, who saved it and the remark for each product.

Takes the inventory already saved in the dashboard and subtracts the weekly sales uploads (Upload Data page). Nothing is changed in the database.
